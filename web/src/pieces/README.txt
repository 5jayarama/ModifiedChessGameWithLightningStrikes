The SVG files here are the "maestro" piece set by sadsnake1, from lichess
(https://github.com/lichess-org/lila/tree/master/public/piece/maestro),
licensed CC BY-NC-SA 4.0 (https://creativecommons.org/licenses/by-nc-sa/4.0/). Unmodified.

To use different pieces, drop PNG files with the same names (wK.png, bQ.png, ...) in this
folder and rebuild. PNGs take priority over the SVGs.
